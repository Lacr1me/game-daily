# 每日民生日报版式规范

## 页面骨架

- 竖版超长单页，宽高关系接近参考图的1:2；默认CSS画布宽1800px，最终以2倍比例渲染，输出宽度不低于3600px。
- 白色纸张背景，外围浅灰细边框；内容由“顶部信息区—四列正文区—今日观察—页脚”纵向组成。
- 顶部约占页面高度10%，正文约占80%，观察与页脚约占10%。

## 顶部信息区

- 左侧约36%：大号红色宋/Ming体“民生日报”，下方红色短横线与“每日35条精选新闻”。
- 中部约29%：左侧红色竖线；上部显示日历图标、公历日期、星期和农历；原天气位置保持纯白留空，不放文字、图标或占位提示。
- 右侧约35%：左侧红色竖线；标题“今日3件大事”；三行摘要，每行由彩色数字方块和单行标题构成。

## 四列正文

- 列间距一致，所有卡片顶部圆角、细描边、白底；栏目标题白字置于纯色栏头。
- 第一列“中国时政与民生”：红色，10条，约占页面内容宽度30%。
- 第二列“全球国际”：紫色，10条，约占23%。
- 第三列“中国科技”：绿色，10条，约占23%。
- 第四列：约占24%，上半蓝色“AI科技”5条，下半紫色或深蓝色“数据速览”。
- 每条新闻按“彩色编号方块＋黑色粗体标题—摘要—来源与时间”排列。编号颜色继承栏目色；条目之间用留白和淡色分隔线区分。
- 标题最醒目，摘要次之，来源和时间字号最小但必须清晰。避免两端对齐产生异常字距。

## 数据速览

- 采用易扫读的纵向指标列表；每项含小图标、指标名、数值、单位和日期/涨跌信息。
- 金价、油价、汇率和股指使用不同但克制的强调色；数据卡底部显示截至时间和来源。

## 今日观察与页脚

- 今日观察为横跨整页的浅橙底圆角框，左侧橙色日历/观察图标，标题橙色，正文黑色。
- 最底部左侧显示“数据来源”，右侧显示“制作时间：YYYY-MM-DD HH:mm”。

## 视觉语言

- 主色：民生红 `#d71920`；国际紫 `#6a19d8`；科技绿 `#079447`；AI蓝 `#0876d1`；观察橙 `#f39800`。
- 正文字色 `#161616`，次级字色 `#555`，边框 `#d9dce3`，背景 `#ffffff`。
- 大标题使用中文宋/Ming体；其余使用微软雅黑或等价中文无衬线字体。
- 不使用照片作为正文背景，不添加二维码、广告、装饰性水印或与信息无关的插画。
